# MTPADMIN

**MTPADMIN** — простой установщик и панель управления Telegram MTProto Proxy на базе TeleMT.

Он подходит, если хочется один раз поставить прокси на сервер, а дальше управлять им без постоянного редактирования конфигов вручную. Есть русское консольное меню и лёгкая веб-панель.

## Что умеет

- устанавливать и запускать MTProto Proxy;
- создавать Classic, Secure и Fake-TLS ссылки;
- показывать активных клиентов прямо сейчас;
- хранить историю подключений, online и трафика;
- строить графики клиентов, соединений, трафика и online;
- показывать страну, город, ASN и провайдера;
- показывать активность на карте мира;
- обновлять данные веб-панели в фоне без перезагрузки страницы;
- создавать отдельные источники/ссылки для сайта, рекламы, друзей и других задач;
- работать с advertising tag от `@MTProxyBot`;
- наблюдать подозрительные обращения через Scanner Guard;
- вручную блокировать IP и добавлять их в whitelist;
- проверять PSI памяти, swap и ресурсы сервера;
- делать резервные копии;
- обновляться без остановки самого MTProxy.

Docker не нужен.

---

## Установка на новый сервер

Поддерживаются Ubuntu/Debian с `systemd`.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

После установки открыть консольное меню можно командой:

```bash
mtpadmin
```

---

## Обновление

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед обновлением автоматически создаётся резервная копия.

Начиная с 0.7.0 обновления рассчитаны на работу без заметного перерыва:

- TeleMT не перезапускается обычным обновлением MTPADMIN;
- новая веб-панель сначала запускается на standby-порту;
- после healthcheck Caddy переключается между blue/green backend;
- старый backend выключается только после успешной стабилизации нового;
- Scanner Guard не снимает действующие блокировки;
- collector и Scanner Guard используют hot-reload.

В 0.8.2 финальный CLI дополнительно нормализуется: legacy-дубликаты `security/resources/doctor` физически удаляются, а Caddy candidate форматируется до validate.

## Веб-панель

Если Caddy уже установлен, веб-панель можно добавить так:

```bash
TMP=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/web-install.sh -o "$TMP" && sudo bash "$TMP"; rm -f "$TMP"
```

Установщик спросит домен панели, логин и пароль. Пароль в открытом виде не сохраняется.

### Фоновое обновление

Страницы сами подтягивают свежие данные без полного reload браузера:

- обзор и активные клиенты — примерно каждые 5 секунд;
- Scanner Guard и система — примерно каждые 10 секунд;
- статистика, клиенты, география, источники и ссылки — примерно каждые 15 секунд;
- при возвращении на вкладку данные обновляются сразу;
- если пользователь редактирует поле формы, DOM временно не заменяется.

### Разделы панели

**Обзор** — состояние прокси, текущие показатели и, начиная с **0.9.0**, тренды: online сейчас, активные IP, изменение числа уникальных клиентов и трафика относительно предыдущего периода. Ниже отображается график online за последние часы.

**Статистика** — таблицы и графики уникальных IP, сеансов, соединений и трафика за сегодня, вчера, 7 дней, 30 дней или всё время.

**Клиенты** — история IP, которые подключались к прокси.

**Активные** — клиенты, подключённые прямо сейчас. Показываются источник, IP, страна, город, ASN, провайдер и статус Scanner Guard. В **0.9.0** добавлена история online: collector сохраняет снимок количества соединений и активных IP каждые 30 секунд.

**География** — карта мира, страны, города и провайдеры. Координаты считаются локально по DB-IP. Базовая карта кэшируется сервером и отдаётся браузеру с того же домена. Есть tooltip, логарифмическое масштабирование и разведение близких точек.

**Источники** — отдельные ссылки и secrets, например `SITE`, `TG_AD_01`, `FRIENDS`.

**Ссылки** — готовые Classic, Secure и Fake-TLS ссылки.

**Безопасность** — Scanner Guard, наблюдения, Risk score, блокировки и whitelist. В **0.9.0** добавлены график распределения Risk за 24 часа и список наиболее часто встречающихся подозрительных ASN/сетей.

**Система** — диагностика, memory PSI, swap activity, ресурсы, backup, GeoIP и логи.

## Online history и графики

В 0.9.0 collector создаёт отдельную таблицу `online_samples`.

- снимок сохраняется примерно раз в 30 секунд;
- сохраняется количество текущих соединений и активных IP по источникам и глобально;
- высокодетальная online-история хранится 31 день;
- дневные агрегаты клиентов и трафика продолжают храниться по прежним retention-настройкам;
- графики рисуются встроенным SVG, без CDN и тяжёлых JS-библиотек.

## Scanner Guard

Scanner Guard наблюдает новые подключения к порту MTProxy и сравнивает их с клиентами, которых действительно видел TeleMT.

Статусы:

- `CLIENT` — подтверждённый клиент TeleMT;
- `UNKNOWN` — данных пока недостаточно;
- `HOSTING?` — подозрительное обращение из сети хостинга/VPS;
- `SCAN` — повторные обращения, которые так и не стали обычным клиентским подключением;
- `WHITELIST` — адрес добавлен в белый список;
- `BANNED` — адрес заблокирован.

Risk 0–100 — только подсказка администратору. `SCAN`, `HOSTING?` и высокий Risk не доказывают принадлежность IP какой-либо организации.

**Автобан выключен.** IP блокируются только вручную.

## Диагностика памяти

`mtpadmin doctor` проверяет Linux PSI (`/proc/pressure/memory`), поэтому просто занятый swap сам по себе не считается проблемой. В «Система» также доступны swap in/out и major faults.

## География и приватность

Страна, регион, город, ASN, сеть и координаты точек определяются локально по DB-IP Lite. IP клиентов не отправляются во внешний GeoIP API. Геолокация IP приблизительна и не является точным местоположением человека.

## Безопасность данных

В публичный репозиторий не попадают MTProxy secrets, advertising tags, пароль панели, IP клиентов, база статистики, ban/whitelist конкретного сервера и резервные копии.
