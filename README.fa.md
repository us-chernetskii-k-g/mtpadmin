# MTPADMIN — پراکسی شخصی تلگرام با پنل وب

[Русский](README.md) · [Українська](README.uk.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md) · [Türkçe](README.tr.md) · [العربية](README.ar.md) · [English](README.en.md)

**MTPADMIN کمک می‌کند روی یک سرور معمولی، پراکسی شخصی تلگرام خودتان را راه‌اندازی کنید و بعد همه‌چیز را از یک پنل وب ساده مدیریت کنید.**

نسخه فعلی: **0.12.5**  
وضعیت: **آزمایش عمومی**. به‌روزرسانی یک نصب فعال روی سرور واقعی آزمایش شده است. در حال حاضر بیشترین نیاز ما بازخورد درباره نصب کاملاً تازه روی سرورهای مختلف Debian و Ubuntu است.

پس از نصب دو روش اتصال دارید:

- **MTProto Proxy** معمولی؛
- **Telegram WEB Proxy** از طریق HTTPS.

در پنل می‌توانید کاربران فعال، آمار، کشور و شبکه، لینک‌های جداگانه برای دوستان یا تبلیغات، وضعیت سرور و به‌روزرسانی‌ها را ببینید.

> یک بار نصب کنید؛ بعد از آن تقریباً همه کارها از مرورگر انجام می‌شود.

## چه امکاناتی دارد؟

- لینک و QR آماده برای اتصال می‌سازد؛
- کاربران فعال را نشان می‌دهد؛
- آمار روزانه و آمار هر منبع را نگه می‌دارد؛
- کشور، شهر و شبکه کاربر را نشان می‌دهد؛
- می‌توانید برای دوستان، سایت یا تبلیغات لینک‌های جدا بسازید؛
- وضعیت پراکسی و پنل را بررسی می‌کند؛
- MTPADMIN، TeleMT و Telegram WEB Proxy را از داخل مرورگر به‌روزرسانی می‌کند؛
- هنگام به‌روزرسانی عادی، لینک فعلی WEB Proxy را حفظ می‌کند؛
- روی گوشی می‌توان پنل را به صفحه اصلی اضافه کرد؛
- Scanner Guard فعالیت مشکوک را نشان می‌دهد. مسدودسازی خودکار به‌طور پیش‌فرض خاموش است.

اطلاعات جغرافیایی روی خود سرور پردازش می‌شود و فهرست IP کاربران برای تشخیص کشور یا شهر به سرویس خارجی فرستاده نمی‌شود.

## قبل از نصب چه لازم است؟

یک سرور تمیز با این شرایط:

- **Debian یا Ubuntu**؛
- معماری x86-64 یا ARM64؛
- IPv4 عمومی؛
- دسترسی `root` یا `sudo`؛
- حداقل **۱ گیگابایت فضای خالی**؛
- دامنه‌هایی که از قبل به IP همین سرور اشاره می‌کنند.

بهتر است سه نام آماده کنید:

```text
proxy.example.com       — MTProto Proxy
panel.example.com       — پنل MTPADMIN
webproxy.example.com    — Telegram WEB Proxy
```

برای پنل و WEB Proxy پورت‌های `80` و `443` باید قابل دسترسی باشند. برای MTProto هم باید پورت انتخابی شما، مثلاً `8443`، باز باشد.

MTPADMIN تنظیمات SSH شما را تغییر نمی‌دهد و کل فایروال سرور را بازنویسی نمی‌کند. فقط برای بخش داخلی WEB Proxy یک قانون حفاظتی جداگانه اضافه می‌کند.

## نصب

با SSH وارد سرور شوید و این دستور را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

نصب‌کننده دامنه‌ها، IP سرور، پورت، نام اولین منبع، رمز پنل و چند گزینه دیگر را از شما می‌پرسد.

قبل از شروع تغییرات، خلاصه تنظیمات نمایش داده می‌شود تا اگر چیزی اشتباه است بتوانید نصب را متوقف کنید.

---

## بعد از نصب

آدرس پنل را باز کنید، مثلاً:

```text
https://panel.example.com/
```

از بخش لینک‌ها، پراکسی را به Telegram اضافه کنید. کاربران فعال و آمار را در پنل می‌بینید و به‌روزرسانی‌ها از بخش عملیات انجام می‌شوند.

برای بررسی کامل سرور:

```bash
mtpadmin doctor
```

اگر همه‌چیز درست باشد، در پایان `RESULT: HEALTHY` نمایش داده می‌شود.

---

## به‌روزرسانی

روش اصلی از داخل پنل وب است: **Operations → Updates**.

اگر پنل در دسترس نبود:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

بستن تب مرورگر، عملیات به‌روزرسانی روی سرور را متوقف نمی‌کند.

## آزمایش عمومی نسخه 0.12.5

به‌روزرسانی MTPADMIN، TeleMT و Telegram WEB Proxy، حفظ لینک WEB Proxy و بررسی نهایی سلامت روی یک سرور واقعی آزمایش شده است.

بیشترین نیاز ما الآن گزارش نصب **از صفر روی یک سرور تازه** است.

اگر مشکلی دیدید، خروجی این دو دستور را بفرستید:

```bash
mtpadmin doctor
systemctl --failed --no-pager
```

رمزها، کلیدها و secretهای پراکسی را منتشر نکنید.
