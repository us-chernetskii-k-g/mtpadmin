# MTPADMIN

**MTPADMIN** — простой установщик и панель управления Telegram MTProto Proxy на базе TeleMT.

Он подходит, если хочется один раз поставить прокси на сервер, а дальше управлять им без постоянного редактирования конфигов вручную.

Есть русское консольное меню и лёгкая веб-панель.

## Что умеет

- устанавливать и запускать MTProto Proxy;
- создавать Classic, Secure и Fake-TLS ссылки;
- показывать, работает ли прокси;
- показывать активных клиентов прямо сейчас;
- хранить историю подключений;
- считать трафик и статистику;
- показывать страну, город, ASN и провайдера;
- показывать активность на карте мира;
- обновлять данные веб-панели в фоне без перезагрузки страницы;
- создавать отдельные ссылки для сайта, рекламы, друзей и других источников;
- считать статистику по каждому источнику отдельно;
- работать с advertising tag от `@MTProxyBot`;
- делать резервные копии;
- проверять состояние сервера и реальное давление по памяти;
- наблюдать подозрительные обращения к порту прокси;
- вручную блокировать IP и добавлять их в whitelist;
- обновляться без остановки самого MTProxy.

Docker не нужен.

## Установка на новый сервер

Поддерживаются Ubuntu/Debian с `systemd`.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Установщик спросит основные параметры прокси и сам подготовит MTPADMIN.

После установки открыть консольное меню можно командой:

```bash
mtpadmin
```

## Обновление

Для уже установленного MTPADMIN:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед обновлением автоматически создаётся резервная копия.

Начиная с версии **0.7.0**, обновления рассчитаны на работу без заметного перерыва:

- MTProxy продолжает работать;
- TeleMT не перезапускается обычным обновлением MTPADMIN;
- новая веб-панель сначала проверяется на standby-порту, а уже потом становится активной;
- Caddy переключается между blue/green backend через graceful reload;
- старая веб-панель выключается только после успешной стабилизации новой;
- Scanner Guard не снимает действующие блокировки во время обновления;
- collector и Scanner Guard поддерживают горячую загрузку нового кода.

В **0.8.2** итоговый CLI перед установкой дополнительно нормализуется: legacy-реализации `security/resources/doctor` удаляются из собранного `/usr/local/bin/mtpadmin`, а CI требует ровно одно финальное определение каждой функции. Caddy candidate автоматически форматируется перед validate, поэтому штатный seamless-update не засоряет консоль предупреждениями о форматировании.

## Веб-панель

Если на сервере уже установлен Caddy, можно добавить веб-панель.

Запускайте интерактивный установщик как обычный временный файл:

```bash
TMP=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/web-install.sh -o "$TMP" && sudo bash "$TMP"; rm -f "$TMP"
```

Установщик спросит домен панели, логин администратора и пароль. Пароль в открытом виде не сохраняется.

### Фоновое обновление

Начиная с **0.8.0**, страницы панели сами подтягивают свежие данные без полного reload браузера.

- обзор и активные клиенты — примерно каждые 5 секунд;
- Scanner Guard и системные показатели — примерно каждые 10 секунд;
- статистика, клиенты, география, источники и ссылки — примерно каждые 15 секунд;
- при возвращении на вкладку данные обновляются сразу;
- если пользователь печатает в input/select/textarea, обновление DOM временно откладывается;
- введённые значения форм сохраняются между фоновыми обновлениями.

В верхней части панели отображается состояние фонового обновления и время последней успешной синхронизации.

### Разделы панели

**Обзор** — состояние прокси, текущие соединения, трафик и краткая статистика.

**Статистика** — клиенты и трафик за сегодня, вчера, 7 дней, 30 дней или всё время.

**Клиенты** — история IP, которые подключались к прокси.

**Активные** — отдельная страница с клиентами, подключёнными прямо сейчас. Показываются источник, IP, страна, город, ASN, провайдер и статус Scanner Guard. Есть локальный поиск по таблице.

**География** — карта мира, страны, города и провайдеры клиентов. Координаты точек берутся из локальной DB-IP. Базовая equirectangular-карта кэшируется самим сервером и затем отдаётся браузеру с того же домена; клиентские IP наружу не отправляются. В 0.8.2 добавлены hover-tooltip с представительным городом и статистикой страны, логарифмическое масштабирование точек и лёгкое разведение перекрывающихся маркеров в плотных регионах. Можно переключать размер точек между уникальными IP и сеансами.

**Источники** — отдельные ссылки и secrets, например `SITE`, `TG_AD_01`, `FRIENDS`.

**Ссылки** — готовые Classic, Secure и Fake-TLS ссылки для подключения.

**Безопасность** — Scanner Guard, наблюдения, Risk score, блокировки и whitelist.

**Система** — диагностика, memory PSI, swap activity, ресурсы, backup, GeoIP и логи.

## Scanner Guard

Scanner Guard наблюдает новые подключения к порту MTProxy и сравнивает их с клиентами, которых действительно видел TeleMT.

Статусы:

- `CLIENT` — подтверждённый клиент TeleMT;
- `UNKNOWN` — данных пока недостаточно;
- `HOSTING?` — обращение выглядит подозрительно и пришло с сети хостинга/VPS;
- `SCAN` — повторные обращения, которые так и не стали обычным клиентским подключением;
- `WHITELIST` — адрес добавлен вами в белый список;
- `BANNED` — адрес заблокирован.

### Risk score

Risk 0–100 — подсказка администратору, а не автоматический приговор IP. Чем выше число, тем сильнее поведение похоже на повторное сканирование.

Scanner Guard показывает количество SYN-подключений, средний интервал между попытками, последнее обращение, последнее подтверждение TeleMT, страну, город, ASN, сеть и историю смены статуса.

Можно фильтровать записи по периоду и статусу, а также искать по IP, городу, ASN или названию провайдера.

### Автоматическая блокировка

**Автобан выключен.**

`SCAN`, `HOSTING?` и Risk score являются только подсказками для администратора. Они не доказывают принадлежность IP какой-либо конкретной организации.

IP можно заблокировать вручную на 24 часа, 7 дней, 30 дней или навсегда.

## Диагностика памяти

MTPADMIN не считает заполненный swap проблемой сам по себе.

`mtpadmin doctor` проверяет Linux PSI (`/proc/pressure/memory`) и оценивает реальное текущее давление на память. В разделе «Система» также показываются swap in/out и major faults, поэтому старые холодные страницы в swap не путаются с реальной нехваткой RAM.

Начиная с **0.8.1** runtime-проверки PSI, Scanner Guard и состояния blue/green web-slot гарантированно подключаются как shell-функции. В **0.8.2** legacy-дубликаты удаляются уже из финального исполняемого CLI, а не просто перекрываются более поздними определениями.

## География и приватность

MTPADMIN определяет страну, регион, город, ASN и сеть по локальным базам DB-IP Lite. IP клиентов не отправляются во внешний GeoIP API.

Координаты точек карты также рассчитываются локально по DB-IP. Статическая базовая карта не содержит пользовательских данных и кэшируется сервером. Геолокация IP приблизительна и не является точным местоположением человека.

---

## Безопасность данных

В публичный репозиторий не попадают ваши MTProxy secrets, advertising tags, пароли веб-панели, IP клиентов, база статистики, ban/whitelist конкретного сервера и резервные копии.
