# MTPADMIN

**MTPADMIN** — простой способ поднять и управлять Telegram MTProto Proxy на своём сервере.

После установки не нужно вручную разбираться в конфигурации TeleMT: основные действия доступны через русское консольное меню, а начиная с версии **0.5** — ещё и через лёгкую веб-панель.

## Что умеет

- запускать MTProto Proxy на базе TeleMT;
- создавать обычные, Secure и Fake-TLS ссылки;
- показывать онлайн-подключения и трафик;
- вести статистику за сегодня, вчера, 7 и 30 дней;
- показывать IP клиентов;
- определять страну, регион, город, ASN и оператора сети;
- создавать отдельные источники ссылок, например `SITE`, `TG_AD_01`;
- считать статистику отдельно по каждому источнику;
- задавать лимиты подключений и уникальных IP;
- работать с advertising tag от `@MTProxyBot`;
- делать резервные копии и диагностику;
- безопасно обновляться из GitHub;
- управляться через защищённую веб-панель.

Docker не требуется.

---

# Установка на новый сервер

Поддерживаются Ubuntu/Debian с `systemd`.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Установщик спросит домен или адрес прокси, публичный IP, порт, secret, Fake-TLS домен и при необходимости advertising tag.

После установки запустите:

```bash
mtpadmin
```

---

# Обновление

Для уже установленного MTPADMIN:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед заменой файлов автоматически создаётся резервная копия. Работающий TeleMT при обычном обновлении MTPADMIN не перезапускается.

Если веб-панель уже установлена, эта же команда обновит и её backend.

# Веб-панель

Если на сервере уже установлен **Caddy**, панель можно добавить одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/web-install.sh | sudo bash
```

Установщик спросит:

- домен панели;
- логин администратора;
- пароль.

Например, если прокси работает на `deimos.example.com:8443`, веб-панель может открываться по адресу:

```text
https://deimos.example.com/
```

MTProxy продолжит работать на своём порту и не конфликтует с HTTPS.

Панель показывает:

- текущее состояние прокси;
- подключения и активные IP;
- статистику и трафик;
- клиентов;
- страны, города и провайдеров;
- источники и ссылки;
- диагностику, ресурсы и логи.

Из панели можно создавать/включать/отключать источники, менять secret, делать backup, обновлять GeoIP и перезапускать TeleMT.

Пароль в открытом виде не сохраняется. Caddy хранит только его хэш. Backend панели слушает только локальный адрес сервера и напрямую из Интернета недоступен.

# Основное меню

Запустите:

```bash
mtpadmin
```

и выберите нужный пункт:

```text
 [1] Живой монитор
 [2] Статистика по периодам
 [3] История трафика
 [4] Клиенты / история IP
 [5] География / города / провайдеры
 [6] Источники / секреты
 [7] Ссылки / QR
 [8] Реклама
 [9] Безопасность
[10] Ресурсы сервера
[11] Логи
[12] Диагностика
[13] Настройки
[14] Резервная копия
[15] Обновить TeleMT
[16] Обслуживание / очистка
[17] Настройка геобазы
 [0] Выход
```

# Полезные команды

Проверить, всё ли работает:

```bash
mtpadmin doctor
```

Посмотреть статистику:

```bash
mtpadmin stats today
mtpadmin stats 7d
mtpadmin stats 30d
```

Посмотреть клиентов:

```bash
mtpadmin ips
```

Посмотреть географию и провайдеров:

```bash
mtpadmin geo today
mtpadmin geo 7d
```

Настроить локальные GeoIP-базы:

```bash
mtpadmin geo-setup
```

Посмотреть источники:

```bash
mtpadmin sources
```

Получить ссылки:

```bash
mtpadmin links
```

# Источники

Можно сделать несколько отдельных ссылок для одного прокси, например:

```text
MAIN
SITE
TG_AD_01
FRIENDS
```

Это позволяет понять, откуда пришли пользователи, и при необходимости отключить или заменить только одну ссылку, не затрагивая остальные.

---

# География

MTPADMIN может локально определять:

- страну;
- регион;
- город;
- ASN;
- оператора/сеть.

Для этого используются локальные базы DB-IP Lite. IP клиентов не отправляются во внешний GeoIP API.

Город по IP определяется приблизительно и не должен рассматриваться как точное местоположение человека.

---

# Безопасность

MTPADMIN старается не вмешиваться в остальные сервисы сервера.

В репозиторий не попадают ваши:

- MTProxy secrets;
- advertising tags;
- пароли веб-панели;
- IP клиентов;
- база статистики;
- резервные копии.

Перед применением важных изменений создаются backup-файлы, а конфигурация проверяется до перезагрузки сервисов.
