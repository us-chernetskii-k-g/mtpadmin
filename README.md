# MTPADMIN

**MTPADMIN** — простая система управления MTProto Proxy через удобное русское меню.

Проект построен на базе [TeleMT](https://github.com/telemt/telemt) и предназначен для тех, кто хочет быстро поднять свой Telegram MTProxy на VPS, видеть статистику подключений и управлять прокси без ручного редактирования конфигов.

После установки достаточно выполнить:

```bash
mtpadmin
```

и пользоваться меню.

---

## Что умеет MTPADMIN

Сейчас MTPADMIN позволяет:

- установить и запустить MTProto Proxy;
- использовать обычные и Fake-TLS ссылки;
- смотреть, работает ли прокси прямо сейчас;
- видеть количество подключений и активных пользователей;
- смотреть статистику за сегодня, вчера, 7 дней, 30 дней и всё время;
- учитывать трафик;
- видеть IP клиентов;
- определять страну, регион и город подключения;
- определять сеть и провайдера по ASN;
- создавать несколько отдельных ссылок/источников;
- смотреть статистику отдельно по каждому источнику;
- задавать отдельные advertising tag для разных источников;
- ограничивать количество подключений и уникальных IP;
- делать резервные копии;
- обновлять MTPADMIN;
- обновлять TeleMT;
- выполнять автоматическую диагностику системы.

Все основные функции доступны через русское консольное меню.

---

## Что понадобится

Подойдёт обычный VPS или выделенный сервер с:

- Ubuntu или Debian;
- доступом `root` или `sudo`;
- публичным IPv4;
- доменом — желательно, но можно использовать и IP;
- свободным TCP-портом для MTProxy.

Docker не нужен.

MTPADMIN подходит и для небольших VPS с небольшим количеством оперативной памяти.

# Установка

На новом сервере выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Установщик задаст несколько вопросов.

Например:

- домен прокси;
- публичный IP сервера;
- порт;
- название основного источника;
- MTProxy secret;
- Fake-TLS домен;
- advertising tag, если он у вас есть.

Если secret ещё нет, установщик может создать его.

После установки запустите:

```bash
mtpadmin
```

# Главное меню

MTPADMIN открывает обычное текстовое меню примерно такого вида:

```text
 [1] Живой монитор
 [2] Статистика по периодам
 [3] История трафика
 [4] Клиенты / история IP
 [5] География / города / провайдеры
 [6] Источники / секреты
 [7] Ссылки / QR
 [8] Реклама
 [9] Безопасность
[10] Ресурсы сервера
[11] Логи
[12] Диагностика
[13] Настройки
[14] Резервная копия
[15] Обновить TeleMT
[16] Обслуживание / очистка
 [0] Выход
```

Большинству пользователей достаточно просто запускать:

```bash
mtpadmin
```

и выбирать нужный пункт.

# Как посмотреть состояние прокси

```bash
mtpadmin doctor
```

Команда проверит основные компоненты и покажет, всё ли работает.

Например:

```text
PASS  TeleMT работает
PASS  Порт прокси открыт
PASS  API доступен
PASS  Статистика работает
PASS  DNS настроен
PASS  GeoIP работает

RESULT: HEALTHY
```

---

# Живой монитор

```bash
mtpadmin dashboard
```

Показывает текущую работу прокси в реальном времени:

- активные подключения;
- количество IP;
- трафик;
- состояние сервера;
- активные источники.

Для выхода нажмите `Ctrl+C`.

---

# Статистика

Сегодня:

```bash
mtpadmin stats today
```

За последние 7 дней:

```bash
mtpadmin stats 7d
```

За 30 дней:

```bash
mtpadmin stats 30d
```

За всё сохранённое время:

```bash
mtpadmin stats all
```

---

# Клиенты и IP

```bash
mtpadmin ips
```

Можно увидеть:

- IP;
- источник;
- страну;
- город;
- ASN;
- провайдера/оператора сети;
- когда IP появился впервые;
- когда был замечен последний раз.

---

# География

Чтобы включить определение городов и провайдеров:

```bash
mtpadmin geo-setup
```

После этого можно смотреть географию подключений.

Сегодня:

```bash
mtpadmin geo today
```

За 7 дней:

```bash
mtpadmin geo 7d
```

MTPADMIN показывает:

- страны;
- города;
- регионы;
- ASN;
- операторов и провайдеров сетей.

Определение выполняется локально на сервере. IP клиентов не отправляются стороннему GeoIP API.

> Геолокация по IP приблизительная. Особенно это касается мобильных операторов, VPN, CGNAT и дата-центров.

# Несколько ссылок и источников

Можно создать несколько отдельных MTProxy-ссылок и понимать, откуда приходят пользователи.

Например:

```text
MAIN
SITE
TG_AD_01
TG_AD_02
FRIENDS
```

Посмотреть источники:

```bash
mtpadmin sources
```

Добавить новый:

```bash
mtpadmin source-add SITE
```

Получить его ссылки:

```bash
mtpadmin source-links SITE
```

Это удобно, если вы размещаете прокси на сайте, покупаете рекламу в разных каналах или хотите раздавать разные ссылки разным группам пользователей.

---

# Ссылки для подключения

```bash
mtpadmin links
```

MTPADMIN показывает готовые ссылки, которые можно открыть в Telegram или отправить пользователю.

Поддерживаются разные режимы, включая Fake-TLS.

Если установлен `qrencode`, QR-код можно вывести прямо в терминале.

---

# Рекламный канал

Если у вас есть advertising tag от `@MTProxyBot`, его можно указать при установке или позже в настройках.

MTPADMIN также поддерживает разные advertising tag для разных источников.

Проверить текущие настройки можно через раздел:

```text
Реклама
```

в основном меню.

---

# Обновление MTPADMIN

Чтобы обновить уже установленный MTPADMIN:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед обновлением автоматически создаётся резервная копия.

Обновление MTPADMIN не должно менять ваши рабочие:

- secret;
- порт;
- advertising tag;
- накопленную статистику;
- GeoIP-базы.

---

# Резервные копии

В основном меню выберите:

```text
Резервная копия
```

или используйте соответствующую команду MTPADMIN.

Перед важными изменениями MTPADMIN также старается автоматически сохранять предыдущую конфигурацию.

---

# Безопасность

MTPADMIN специально устроен так, чтобы служебные интерфейсы TeleMT не выставлялись напрямую в Интернет.

В GitHub **не хранятся** ваши:

- MTProxy secret;
- advertising tag;
- реальные IP клиентов;
- пароли;
- статистика;
- резервные копии рабочего сервера.

Все персональные настройки остаются на вашем сервере.

---

# Если что-то не работает

Первое, что стоит выполнить:

```bash
mtpadmin doctor
```

Затем посмотреть статус:

```bash
mtpadmin status
```

и логи через пункт **«Логи»** в главном меню.

При обращении за помощью лучше присылать вывод `mtpadmin doctor`, но **не публикуйте свои secret и пароли**.

# Веб-панель

В разработке лёгкая веб-панель MTPADMIN с русским интерфейсом.

Планируется:

- вход по логину и паролю;
- красивый dashboard;
- онлайн-пользователи;
- статистика и графики;
- города и провайдеры;
- управление источниками;
- создание ссылок;
- Scanner Guard;
- ручная блокировка и разблокировка IP;
- управление основными настройками через браузер.

При этом сама панель будет лёгкой и рассчитанной на небольшие VPS.
