# MTPADMIN — власний Telegram Proxy з веб-панеллю

[Русский](README.md) · [Українська](README.uk.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md) · [Türkçe](README.tr.md) · [العربية](README.ar.md) · [English](README.en.md)

**MTPADMIN допомагає за кілька хвилин підняти власний проксі для Telegram на звичайному сервері та керувати ним через зрозумілу веб-панель.**

Поточна версія: **0.12.5**  
Статус: **відкрите тестування**. Оновлення вже працюючої установки перевірено на реальному сервері. Особливо потрібні відгуки про чисте встановлення на різних серверах Debian/Ubuntu.

Після встановлення ви отримаєте два способи підключення:

- звичайний **MTProto Proxy**;
- **Telegram WEB Proxy** через HTTPS.

У панелі можна побачити активних користувачів, статистику, країни та мережі, створювати окремі посилання для друзів або реклами, перевіряти стан сервера й встановлювати оновлення.

> Встановили один раз — далі майже все робиться через браузер.

## Що вміє MTPADMIN

- створює готові посилання та QR-коди;
- показує активні підключення;
- веде статистику за днями та джерелами;
- показує країну, місто й мережу клієнта;
- дозволяє робити окремі посилання для друзів, сайту чи реклами;
- перевіряє стан проксі та веб-панелі;
- оновлює MTPADMIN, TeleMT і Telegram WEB Proxy прямо з браузера;
- зберігає вже роздане посилання WEB Proxy під час звичайного оновлення;
- може працювати як окремий застосунок на телефоні;
- має Scanner Guard для перегляду підозрілої активності. Автоматичне блокування за замовчуванням вимкнене.

Географія визначається локально на вашому сервері. Список IP клієнтів не надсилається сторонньому сервісу для визначення міста або країни.

## Що потрібно перед встановленням

Потрібен чистий сервер з:

- **Debian або Ubuntu**;
- архітектурою x86-64 або ARM64;
- публічним IPv4;
- доступом `root` або `sudo`;
- щонайменше **1 ГБ вільного місця**;
- доменами, які вже вказують на цей сервер.

Найзручніше підготувати три імені:

```text
proxy.example.com       — звичайний MTProto Proxy
panel.example.com       — веб-панель MTPADMIN
webproxy.example.com    — Telegram WEB Proxy
```

Для панелі та WEB Proxy мають бути доступні порти `80` і `443`. Для звичайного MTProto потрібно відкрити обраний порт, наприклад `8443`.

MTPADMIN не змінює налаштування SSH і не переписує весь мережевий екран. Для внутрішніх частин WEB Proxy він додає лише власне захисне правило.

## Встановлення

Увійдіть на сервер через SSH та виконайте:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Майстер сам запитає домени, IP сервера, порт, ім’я першого джерела, пароль веб-панелі та додаткові параметри.

Перед початком змін ви побачите підсумок і зможете відмовитися, якщо щось введено неправильно.

---

## Після встановлення

Відкрийте адресу панелі, наприклад:

```text
https://panel.example.com/
```

Далі зазвичай достатньо відкрити **«Посилання»**, додати проксі в Telegram, переглянути **«Активні»** та час від часу заходити в **«Операції» → «Оновлення»**.

Для повної перевірки:

```bash
mtpadmin doctor
```

Якщо все добре, наприкінці буде `RESULT: HEALTHY`.

---

## Оновлення

Основний спосіб — через веб-панель: **Операції → Оновлення**.

Якщо панель недоступна:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Оновлення продовжується на сервері, навіть якщо ви закрили вкладку браузера.

На реальному сервері вже перевірено оновлення MTPADMIN, TeleMT і Telegram WEB Proxy, збереження чинного WEB-посилання, статистику після оновлення та фінальну перевірку без помилок.

Особливо потрібні відгуки про **чисте встановлення з нуля**.

Якщо виникла проблема, надішліть безпечний вивід:

```bash
mtpadmin doctor
systemctl --failed --no-pager
```

Не публікуйте паролі, секрети проксі та файли з ключами.
