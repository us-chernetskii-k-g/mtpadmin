# MTPADMIN

### Telegram MTProto Proxy, которым удобно управлять

MTPADMIN превращает обычный VPS в готовый Telegram proxy-сервер с веб-панелью, статистикой, картой клиентов, защитой и поддержкой **Telegram WEB Proxy**.

Не нужно вручную собирать конфиги, вспоминать systemd-команды или разбираться, почему после обновления что-то перестало отвечать. Установщик поднимает сервисы, панель показывает состояние системы, а встроенный `doctor` проверяет, что всё действительно работает.

> **Одна установка — MTProxy, WEB Proxy, аналитика и управление из браузера.**

## Что вы получаете

- обычный Telegram MTProxy на базе **TeleMT**;
- **WEB Proxy** на базе официального `telegramdesktop/tproxy-server`;
- Classic, Secure, FakeTLS и WEB-ссылки подключения;
- QR-коды для быстрого подключения телефона;
- красивую русскоязычную веб-панель;
- клиентов online в реальном времени;
- графики подключений, IP и трафика;
- карту стран, городов и сетей клиентов;
- отдельные ссылки для сайта, рекламы, друзей и других источников;
- Scanner Guard для наблюдения за сканами и подозрительными подключениями;
- резервные копии и диагностику сервера;
- бесшовные обновления веб-панели без остановки самого прокси;
- **Update Center** с проверкой новых версий MTPADMIN, TeleMT и WEB Proxy.

Docker не нужен.

## Установка

Подойдёт чистый VPS на Ubuntu/Debian с `systemd` и публичным IP.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Установщик проведёт по основным настройкам и подготовит сервер. После этого консольное меню всегда доступно командой:

```bash
mtpadmin
```

Для уже установленного MTPADMIN обновление выполняется одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед обновлением автоматически создаётся резервная копия. Если первичная установка WEB Proxy оборвалась, повторный запуск продолжит её: уже созданный источник TeleMT будет переиспользован без смены secret.

## Веб-панель

Большинство повседневных задач можно выполнять из браузера.

В панели есть:

**Обзор** — состояние сервера, online сейчас, активные IP, трафик, тренды и графики.

**Статистика** — клиенты, соединения, сеансы и трафик за сегодня, вчера, 7 дней, 30 дней или всё время.

**Активные** — кто подключён прямо сейчас, откуда клиент пришёл, страна, город, ASN и провайдер.

**География** — карта мира и статистика по странам, городам и сетям.

**Источники** — отдельные secrets и ссылки вроде `SITE`, `TG_AD_01`, `FRIENDS` или любых своих названий. Так удобно понимать, какая ссылка реально используется.

**Ссылки** — готовые Classic, Secure, FakeTLS и WEB Proxy ссылки с QR-кодами.

**Безопасность** — Scanner Guard, Risk score, история подозрительных обращений, ручные блокировки и whitelist.

**События** — история обновлений и административных действий.

**Операции** — Health Score, состояние WEB Proxy, Scanner Guard Learning Mode, резервные копии и Update Center.

**Система** — диагностика TeleMT, памяти, диска, collector, Caddy и остальных компонентов.

Панель обновляет данные в фоне — страницы не нужно постоянно перезагружать вручную.

## Telegram WEB Proxy

MTPADMIN умеет поднимать новый WEB-транспорт Telegram через официальный проект:

`telegramdesktop/tproxy-server`

Схема остаётся простой:

```text
Telegram
   ↓ HTTPS :443
WEB Proxy hostname
   ↓
Caddy
   ↓
tproxy-server
   ↓
TeleMT
   ↓
Telegram
```

Отдельный второй MTProxy не запускается: WEB relay использует уже установленный TeleMT как backend. Благодаря этому статистика и источники остаются в одном месте.

Hostname WEB Proxy можно задать самому в панели. Например:

```text
webproxy.example.com
```

Для него нужна обычная DNS A-запись на IP сервера. После этого Caddy автоматически получает TLS-сертификат.

WEB Proxy получает отдельный источник `WEB_PROXY`, поэтому его использование видно отдельно от обычных MTProxy-ссылок.

## Update Center

MTPADMIN следит не только за собственной версией.

Панель показывает:

- установленную и доступную версию **MTPADMIN**;
- установленную и последнюю версию **TeleMT**;
- установленный commit и актуальный upstream **Telegram WEB Proxy**.

Если обновление доступно, в панели появляется уведомление. Компоненты можно обновить из раздела «Операции» без поиска команд по документации.

Начиная с 0.11.3 проверка версии MTPADMIN идёт через GitHub API, а не через кэшируемый raw-URL ветки, поэтому ручная проверка сразу видит актуальный `main`.

Обновление MTPADMIN использует blue/green web deployment: новая панель сначала запускается отдельно и проходит healthcheck, после чего Caddy переключает трафик. Обычное обновление MTPADMIN не перезапускает TeleMT.

## Scanner Guard

Scanner Guard наблюдает обращения к порту MTProxy и сопоставляет их с реальными клиентами TeleMT.

Основные статусы:

- `CLIENT` — подтверждённый клиент;
- `UNKNOWN` — данных пока недостаточно;
- `HOSTING?` — подозрительная активность из сети хостинга/VPS;
- `SCAN` — повторные обращения, которые так и не стали обычным клиентом;
- `WHITELIST` — доверенный IP;
- `BANNED` — заблокированный IP.

Risk score помогает быстро находить подозрительные адреса, но сам по себе ничего не доказывает.

**Автоматические блокировки по умолчанию выключены.**

Learning Mode позволяет посмотреть, кого система *могла бы* заблокировать при разных Risk-порогах, не включая реальный автобан.

## Статистика и приватность

MTPADMIN хранит историю online и строит собственные графики без внешних аналитических сервисов.

География IP определяется локально по DB-IP Lite. IP клиентов не отправляются во внешний GeoIP API. Геолокация IP приблизительна и не является точным местоположением человека.

В публичный GitHub-репозиторий не попадают secrets, advertising tags, пароль панели, IP клиентов, база статистики, whitelist/ban конкретного сервера и резервные копии.

## Диагностика

Если хочется быстро понять, всё ли в порядке:

```bash
mtpadmin doctor
```

Doctor проверяет TeleMT, API, collector, Scanner Guard, веб-панель, WEB Proxy, Caddy, DNS, память, Linux PSI, swap и свободное место.

Полезные команды:

```bash
mtpadmin
mtpadmin doctor
mtpadmin stats today
mtpadmin stats 7d
mtpadmin ips
mtpadmin geo today
mtpadmin guard-status
mtpadmin suspicious
mtpadmin bans
```

---

## Для кого MTPADMIN

Проект подойдёт, если вы хотите свой Telegram proxy и не хотите превращать его обслуживание в отдельную работу.

Он особенно удобен для личного прокси, небольшого публичного сервиса, нескольких рекламных/партнёрских ссылок или собственного Telegram-проекта, где важно видеть реальную статистику использования.
