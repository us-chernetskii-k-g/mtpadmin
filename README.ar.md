# MTPADMIN — بروكسي Telegram شخصي مع لوحة ويب

[Русский](README.md) · [Українська](README.uk.md) · [فارسی](README.fa.md) · [简体中文](README.zh-CN.md) · [Türkçe](README.tr.md) · [العربية](README.ar.md) · [English](README.en.md)

**يساعدك MTPADMIN على تشغيل بروكسي Telegram خاص بك على خادم عادي، ثم إدارته من لوحة ويب بسيطة.**

الإصدار الحالي: **0.12.5**  
الحالة: **اختبار عام**. تم اختبار ترقية تثبيت يعمل فعلياً على خادم حقيقي. نحتاج الآن بشكل خاص إلى تجارب التثبيت الجديد على خوادم Debian وUbuntu مختلفة.

بعد التثبيت تحصل على طريقتين للاتصال:

- **MTProto Proxy** عادي؛
- **Telegram WEB Proxy** عبر HTTPS.

من اللوحة يمكنك مشاهدة المستخدمين النشطين والإحصاءات والبلد والشبكة، وإنشاء روابط منفصلة للأصدقاء أو الموقع أو الإعلانات، وفحص حالة الخادم وتثبيت التحديثات.

## ماذا يقدم MTPADMIN؟

- ينشئ روابط اتصال ورموز QR جاهزة؛
- يعرض الاتصالات النشطة؛
- يحتفظ بإحصاءات يومية ولكل مصدر؛
- يعرض بلد ومدينة وشبكة العميل؛
- يسمح بإنشاء روابط منفصلة للأصدقاء أو الموقع أو الإعلانات؛
- يفحص حالة البروكسي ولوحة الويب؛
- يحدّث MTPADMIN وTeleMT وTelegram WEB Proxy من المتصفح؛
- يحافظ على رابط WEB Proxy الحالي أثناء التحديث العادي؛
- يمكن إضافة اللوحة إلى الشاشة الرئيسية للهاتف؛
- يعرض Scanner Guard النشاط المشبوه، والحظر التلقائي متوقف افتراضياً.

يتم تحديد الموقع الجغرافي على خادمك نفسه، ولا يتم إرسال قائمة عناوين IP للعملاء إلى خدمة خارجية لمعرفة البلد أو المدينة.

## ما المطلوب قبل التثبيت؟

يفضل خادم نظيف يحتوي على:

- **Debian أو Ubuntu**؛
- x86-64 أو ARM64؛
- IPv4 عام؛
- صلاحية `root` أو `sudo`؛
- مساحة فارغة لا تقل عن **1 GB**؛
- أسماء نطاقات تشير مسبقاً إلى هذا الخادم.

الترتيب الأبسط هو ثلاثة أسماء:

```text
proxy.example.com       — MTProto Proxy
panel.example.com       — لوحة MTPADMIN
webproxy.example.com    — Telegram WEB Proxy
```

يجب أن يكون المنفذان `80` و`443` متاحين للوحة وWEB Proxy. كما يجب فتح المنفذ الذي اخترته لـ MTProto، مثل `8443`.

MTPADMIN لا يغير إعدادات SSH ولا يعيد كتابة جدار الحماية بالكامل. يضيف فقط قاعدة حماية منفصلة للخدمات الداخلية الخاصة بـ WEB Proxy.

## التثبيت

ادخل إلى الخادم عبر SSH ثم نفّذ:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

سيطلب منك معالج التثبيت أسماء النطاقات وIP الخادم والمنفذ واسم المصدر الأول وكلمة مرور اللوحة وبعض الخيارات الأخرى.

قبل إجراء أي تغيير على النظام ستظهر لك خلاصة الإعدادات، ويمكنك إلغاء التثبيت إذا وجدت خطأ.

---

## بعد التثبيت

افتح عنوان اللوحة، مثلاً:

```text
https://panel.example.com/
```

أضف البروكسي إلى Telegram من قسم الروابط، ثم تابع المستخدمين والإحصاءات من اللوحة.

للفحص الكامل:

```bash
mtpadmin doctor
```

إذا كان كل شيء سليماً سترى في النهاية `RESULT: HEALTHY`.

---

## التحديث

الطريقة الأساسية هي من لوحة الويب عبر قسم العمليات والتحديثات.

إذا لم تكن اللوحة متاحة:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

إغلاق تبويب المتصفح لا يوقف عملية التحديث على الخادم.

نحتاج الآن خصوصاً إلى تجارب **التثبيت من الصفر على خادم جديد**.

إذا واجهت مشكلة، أرسل المخرجات الآمنة التالية:

```bash
mtpadmin doctor
systemctl --failed --no-pager
```

لا تنشر كلمات المرور أو أسرار البروكسي أو ملفات المفاتيح.
