# MTPADMIN

**MTPADMIN** — простой способ установить и управлять Telegram MTProto Proxy на своём сервере.

Вместо ручного редактирования конфигов вы получаете русское консольное меню и лёгкую веб-панель: можно смотреть подключения, статистику, трафик, географию, создавать отдельные ссылки и контролировать безопасность прокси.

Docker не нужен.

## Что умеет

- устанавливать и запускать MTProto Proxy на базе TeleMT;
- создавать Classic, Secure и Fake-TLS ссылки;
- показывать подключения и активные IP;
- считать трафик и статистику за разные периоды;
- показывать страну, город, ASN и провайдера клиента;
- создавать отдельные источники ссылок, например `SITE`, `TG_AD_01`, `FRIENDS`;
- считать статистику отдельно по каждому источнику;
- задавать лимиты подключений и уникальных IP;
- работать с advertising tag от `@MTProxyBot`;
- делать резервные копии и диагностику;
- управляться через защищённую веб-панель;
- наблюдать подозрительные обращения к порту прокси через Scanner Guard;
- вручную блокировать и разблокировать IP;
- вести whitelist и журнал действий.

# Установка на новый сервер

Поддерживаются Ubuntu/Debian с `systemd`.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

Установщик спросит домен или адрес прокси, публичный IP, порт, secret, Fake-TLS домен и при необходимости advertising tag.

После установки откройте меню:

```bash
mtpadmin
```

---

# Обновление

Для уже установленного MTPADMIN:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед обновлением автоматически создаётся резервная копия. Обычное обновление MTPADMIN не перезапускает работающий TeleMT.

Если веб-панель уже установлена, обновится и она.

# Веб-панель

Если на сервере установлен Caddy, веб-панель можно добавить поверх MTPADMIN.

Для интерактивной установки лучше сначала скачать установщик во временный файл:

```bash
TMP=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/web-install.sh -o "$TMP" && sudo bash "$TMP"; rm -f "$TMP"
```

Установщик спросит домен панели, логин администратора и пароль.

Например, прокси может работать на:

```text
deimos.example.com:8443
```

а панель открываться по адресу:

```text
https://deimos.example.com/
```

Веб-панель показывает:

- состояние прокси;
- текущие подключения;
- статистику и трафик;
- клиентов и IP;
- страны, города и провайдеров;
- источники и ссылки;
- Scanner Guard;
- диагностику, ресурсы и логи.

Пароль в открытом виде не сохраняется. Backend панели доступен только локально на сервере, а вход из Интернета проходит через Caddy.

# Scanner Guard

Начиная с версии **0.6.0**, MTPADMIN умеет наблюдать обращения к порту MTProxy и сравнивать их с реальными клиентами, которых видит TeleMT.

В разделе **Безопасность** можно увидеть статусы:

- `CLIENT` — IP был подтверждён как клиент TeleMT;
- `UNKNOWN` — данных пока недостаточно;
- `HOSTING?` — подозрительное обращение с адреса хостинга/VPS;
- `SCAN` — повторные обращения, которые не стали нормальным клиентским подключением;
- `WHITELIST` — IP добавлен вами в белый список;
- `BANNED` — IP заблокирован вручную.

`SCAN` и `HOSTING?` — только эвристические отметки. Они **не означают**, что IP принадлежит Роскомнадзору, ТСПУ или любой другой конкретной организации.

### Автобан

В версии 0.6.0 **автоматическая блокировка выключена**. Scanner Guard только собирает данные и предлагает их администратору для проверки.

IP можно заблокировать вручную на:

- 24 часа;
- 7 дней;
- 30 дней;
- навсегда.

Заблокированные адреса сохраняются и восстанавливаются после перезагрузки сервера.

MTPADMIN не даст случайно добавить в ban IP самого прокси или локальный служебный адрес.

### Команды Scanner Guard

Состояние:

```bash
mtpadmin guard-status
```

Подозрительные IP:

```bash
mtpadmin suspicious
```

Активные блокировки:

```bash
mtpadmin bans
```

Заблокировать на сутки:

```bash
mtpadmin ban 1.2.3.4 24h
```

Заблокировать на 7 дней:

```bash
mtpadmin ban 1.2.3.4 7d
```

Разблокировать:

```bash
mtpadmin unban 1.2.3.4
```

Добавить в whitelist:

```bash
mtpadmin whitelist 1.2.3.4
```

Удалить из whitelist:

```bash
mtpadmin unwhitelist 1.2.3.4
```

Большинству пользователей удобнее делать это прямо в веб-панели.

# Источники

Для одного прокси можно создать несколько отдельных источников, например:

```text
MAIN
SITE
TG_AD_01
FRIENDS
```

Так можно понять, откуда приходят пользователи, и при необходимости отключить или заменить только одну ссылку, не затрагивая остальных.

---

# География

MTPADMIN может локально определять страну, регион, город, ASN и сеть/провайдера.

Используются локальные базы DB-IP Lite. IP клиентов не отправляются во внешний GeoIP API.

Город по IP определяется приблизительно и не является точным местоположением человека.

---

# Безопасность данных

В публичный репозиторий не попадают ваши:

- MTProxy secrets;
- advertising tags;
- пароли веб-панели;
- IP клиентов;
- база статистики;
- списки ban/whitelist конкретного сервера;
- резервные копии.

Перед важными изменениями MTPADMIN создаёт backup и проверяет новые файлы до их применения.
