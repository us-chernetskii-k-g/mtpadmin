# MTPADMIN · Telegram Proxy от экосистемы VPN BOSS

### Свой Telegram Proxy за одну установку — без постоянной возни с консолью

**MTPADMIN** — бесплатный инструмент экосистемы **VPN BOSS**, который превращает обычный VPS в управляемый Telegram Proxy с веб-панелью, статистикой, готовыми ссылками и автоматическими обновлениями.

> **Установили один раз — дальше управляете из браузера.**

Не нужно каждый раз вспоминать команды, вручную собирать ссылки, следить за сервисами и разбираться, почему очередное обновление что-то сломало. MTPADMIN берёт повседневную работу на себя.

[**VPN BOSS**](https://brakonder.ru) · [**Группа VPN BOSS в Telegram**](https://t.me/boss_of_this_vpn)

## Почему это удобно

- **Свой Telegram Proxy** — сервер и доступ остаются под вашим контролем.
- **Понятная веб-панель** — основные действия без постоянного SSH.
- **Готовые ссылки и QR** — Classic, Secure, FakeTLS и Telegram WEB Proxy.
- **Статистика без сторонних сервисов** — подключения, трафик, география, источники.
- **Единый live-список клиентов** — обычные MTProto и WEB Proxy отображаются вместе с IP, GeoIP и ASN.
- **Самодиагностика** — MTPADMIN сам показывает, что работает, а что требует внимания.
- **Безопасные обновления** — backup, rollback и blue/green для веб-панели.
- **Telegram WEB Proxy** — отдельный HTTPS/443 transport с официальным MTProxy backend.
- **Scanner Guard** — помогает видеть подозрительную активность, не включая агрессивные автоблокировки по умолчанию.

## Быстрый старт

Нужен VPS на Ubuntu/Debian с `systemd` и публичным IP.

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/install.sh | sudo bash
```

После установки можно пользоваться веб-панелью или командой:

```bash
mtpadmin
```

Для установленной системы предпочтительный способ обновления — **MTPADMIN → Операции → Update Center**. Консольный updater остаётся запасным вариантом:

```bash
curl -fsSL https://raw.githubusercontent.com/us-chernetskii-k-g/mtpadmin/main/update.sh | sudo bash
```

Перед изменениями создаются резервные копии, а критические компоненты проходят READY/health проверки.

## Что вы получаете после установки

**Обзор** — состояние сервера и главные показатели без перегруженной технической информации.

**Активные** — единый live-список обычных MTProto и WEB Proxy клиентов. WEB-клиенты получают ту же локальную GeoIP/ASN обработку и ту же политику хранения IP, что и остальные клиенты.

**Ссылки** — готовые подключения и QR-коды; secrets скрыты по умолчанию.

**Статистика** — клиенты, соединения, трафик и динамика по периодам.

**География** — страны, города и сети клиентов.

**Источники** — отдельные ссылки для сайта, друзей, рекламы или других каналов с собственной статистикой. Ad tag и лимиты можно менять позже, а MTPADMIN проверяет, что изменение реально появилось в TeleMT runtime.

**Безопасность** — Scanner Guard, Risk Score, whitelist и ручные блокировки.

**Update Center** — проверка и обновление MTPADMIN, TeleMT и Telegram WEB Proxy прямо из браузера. Операция продолжает работать даже если закрыть вкладку.

**Диагностика** — `doctor` проверяет сервисы, API, DNS, память, swap, диск, WEB Proxy и другие ключевые части системы.

## Telegram WEB Proxy

MTPADMIN использует `telegramdesktop/tproxy-server` и официальный `TelegramMessenger/MTProxy` backend.

Для обычного пользователя это выглядит просто: в панели появляется WEB-ссылка и QR, а HTTPS работает на стандартном порту **443**.

Под капотом схема такая:

```text
Telegram Desktop
      ↓ HTTPS :443
WEB Proxy hostname
      ↓
Caddy → tproxy-server
      ↓ localhost
official MTProxy
      ↓
Telegram
```

WEB transport изолирован от обычного TeleMT proxy. Локальные backend-порты закрываются от внешнего доступа.

Начиная с **0.11.11**, MTPADMIN добавляет к relay небольшой локальный telemetry endpoint. Он доступен только через loopback admin listener и отдаёт панели/collector только активный IP и число carrier-сессий. Capability, proxy secret, session token и URL запросов туда не попадают. Благодаря этому WEB-клиенты отображаются в «Активных», получают локальный GeoIP/ASN и участвуют в общей live-статистике.

Повторная проверка WEB Proxy из Update Center не просто смотрит номер версии: она восстанавливает конфигурацию, безопасные pending limits, локальный backend, telemetry patch и READY-состояние.

## Для тех, кому нужны технические детали

- основной proxy: **TeleMT**;
- WEB relay: **telegramdesktop/tproxy-server** + небольшой MTPADMIN loopback telemetry patch;
- WEB backend: официальный **TelegramMessenger/MTProxy**;
- HTTPS: **Caddy**;
- статистика: локальная SQLite DB;
- GeoIP: локальная DB-IP Lite;
- обновления: отдельные systemd jobs с серверным lock;
- веб-панель: blue/green переключение без остановки TeleMT;
- autoban Scanner Guard: **OFF по умолчанию**.

Полные IP и статистика не отправляются во внешний GeoIP API. Production secrets, пароль панели, клиентская база и резервные копии не должны попадать в публичный репозиторий.
